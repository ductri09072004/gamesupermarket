# Credits

Hiện tại toàn bộ model, texture và âm thanh được **sinh bằng code** (không có asset bên ngoài).

Để thay bằng asset CC0 (kenney.nl, quaternius.com, polyhaven.com, ambientcg.com, freesound.org):
1. Đặt file `.glb` vào `public/assets/models/furniture/` với tên trùng id nội thất (ví dụ `shelf_large.glb`).
2. Thêm đường dẫn vào `public/assets/manifest.json`, ví dụ `{ "models": ["furniture/shelf_large.glb"] }`.
3. Ghi nguồn + license từng file vào bảng dưới.
